# :yarn: Labyrinth
A quick-and-dirty program to generate mazes with box-drawing characters.

<img width="899" height="559" alt="usage" src="https://github.com/user-attachments/assets/d707ae82-7074-4212-bf3d-bdba3b5083b3" />

## Installation

Snag the binary from the latest release, or if you've got [Rust](https://rust-lang.org/) you can build it yourself with `cargo run`

### Usage

```text
labyrinth <width> <height>
```

### Examples

```text
labyrinth 16 8

```

The output is just a string sent to `stdout`, so pipes and redirects work too:

```text
labyrinth 25 25 > maze.txt
```
